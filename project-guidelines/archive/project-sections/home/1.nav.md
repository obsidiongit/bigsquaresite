# Navigation Design Brief

v3, 2026-08-23. Replaces v2 (standard bar + mega menu) after Brad's build review: the center-links bar read as template SaaS chrome. New direction, set by Brad: quiet instrument bar, loud menu (lusion's bar anatomy, e2vc's editorial index). STYLE_GUIDE.md 6.5 rewritten to match.

## The bar

- Fixed, 72px desktop / 64px mobile. Left: `<Logo />` + "BigSquare" wordmark (wordmark hidden under 640px).
- Right: exactly two pills. "Let's Talk" (primary, sm, links /schedule/; label pending Brad's sign-off in copy-rules.md, see STYLE_GUIDE changelog) and "Menu" (secondary, sm, with a small `--acc` square glyph: the pixel motif).
- No center links. All IA lives in the overlay.
- Transparent over the page top; after 40px: `--paper` 85% + 12px blur + hairline border (unchanged from v2).
- The bar and overlay are `data-cursor-quiet` zones.

## The overlay menu

Full-screen `--paper` takeover (Radix Dialog: focus trap, Escape closes, body scroll locked). Hairline rails on. Entry: fade + slide-from-top, 250ms house; rows stagger in (55ms, baseline rise).

- Top row mirrors the bar: logo left, "Close" pill (secondary, rotated square glyph) right.
- Left column, the index: five rows at `--text-menu` (Bluu, new token) with mono bracket indexes. [01] Who We Are, [02] Services, [03] Industries, [04] Results, [05] Contact. Group rows (01 to 03) set the active group: active label goes `--acc` with a small blue square marker; Results and Contact navigate directly. The current page's row keeps the static hand-drawn underline (annotation budget 1 of 3).
- Right column (lg+): the active group's ruled mono link table: eyebrow per sub-group, full-width hairline rows with `↗`, hover slides the arrow and turns the row `--acc`. Services shows all 15 links in the 3 locked groups; default active group.
- Below lg: the group's ruled list opens inline under its row (same data, no separate sheet component).
- Foot row: Login `↗` (obsidion.ai, decisions.md) + "DENVER / TAMPA" mono left; "Schedule a Call" primary pill right (the approved-label ask lives here, not in the hero).
