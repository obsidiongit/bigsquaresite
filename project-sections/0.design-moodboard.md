## Aesthetic keywords
Clean. Measured. Premium. Technical. Confident. Airy.

Not: playful, loud, startup-gradient, neon, glassmorphism-everywhere, stock-photo corporate.

## Scraped reference outcome (2026-08-21)

Nine reference sites were captured in full (desktop + mobile, multiple scroll depths, extracted tokens) into `reference-images/<site>/`, each with an `ANALYSIS.md` ranking what transfers and what does not. The table in `reference-images/README.md` lists all nine and their roles. The synthesis lives in `project-guidelines/STYLE_GUIDE.md`.

Creative direction settled in that pass:
- **E2VC (e2.vc) is the primary identity anchor**: closest token match to Graphite, hand-drawn blue annotation system (bracket CTA, circled hero word, underlines), visible hairline grid, tag-chip metric lockups, per-section theme tokens.
- Every other reference contributes specific elements, not its overall look: lusion (framed hero panel, baseline reveals, easing values, "+" registration marks), pear-no (numbered narrative structure, the house ease, reveal exit motion), pxpush (scroll-effect component catalog, the pixel cursor translated to quiet blue, directional button fills, Nº00x labels), obys-aim (hairline info bars, bracketed indexes), dropbox-brand (visible grid discipline), youtech (page architecture), metacci (conversion narrative, outcome-first case headlines, objection FAQ), readymag (feature bento, one flat H2 size).

Direction changes vs this file (the style guide carries the detail):
- Hero: a framed media panel (rounded, inset on the light page, dark media inside) replaces the full-bleed video hero. The 55 to 65 percent overlay rule applies inside the panel when type sits on media.
- The closing CTA band becomes the site's one full-`--acc` surface; the footer stays a dark panel. Dark panels otherwise remain hero media, proof band, footer.
- Motion: the single fade-up spec grows into a named system (house ease `cubic-bezier(.22,1,.36,1)`, reveal catalog, marquee and velocity rules, reduced-motion table). Fade-up stays the default for blocks.
- New signature elements: rough.js annotations, visible hairline grid + registration marks, Nº section labels, the quiet blue pixel cursor, directional button fills, `--accondark` for accent-on-dark legibility.

The hard rules in this file did not change.

## Build quality bar
Framer or Webflow showcase level. Smooth scroll-triggered reveals, hover states on everything interactive, a hero that moves. Never a static WordPress template feel. Motion should feel expensive and calm, not busy.

## Colors

Default palette: **01 Graphite**. Light, cool neutrals, one blue.

```css
:root {
  /* 01 Graphite (site default) */
  --paper: #F5F6F8;        /* page background */
  --surf: #E9ECF1;         /* cards, alternating sections */
  --mid: #5A6373;          /* secondary text */
  --ink: #0B0F17;          /* primary text */
  --acc: #0657F9;          /* logo blue, primary buttons, links, metrics */
  --acc2: #0A2A73;         /* deep navy, secondary emphasis */
  --onacc: #FFFFFF;
  --onacc2: #FFFFFF;
  --line: rgba(11,15,23,.12);
  --darkpanel: #0B0F17;    /* dark sections (hero overlay, CTA band, footer) */
  --ondark: #E9ECF1;
  --ondarkmid: #8D97A8;
}
```

Rules:
- `#0657F9` is the logo blue. It never changes. Every palette is built around it.
- Metrics and big numbers always use `--acc` or `--acc2`, never `--ink`.
- Dark panels (`--darkpanel`) are for the hero overlay, the closing CTA band, and the footer. The rest of the page is light.
- The logo mark is transparent and sits on any ground without a white box.

Alternate palettes from the brand sheet, available for landing pages, ad creative, or future sections. Do not mix them on one page.

## Typography

- Display (H1, H2, big numbers): **Bluu Next Bold**. Italic and Titling cuts available for emphasis.
- Everything else: **Apfel Grotezk**. Regular for body, Mittel for UI and nav, Fett for H3 and buttons, Satt for rare heavy emphasis.
- Mono (metric labels, eyebrow tags): **IBM Plex Mono** as placeholder. The third font is not locked. Build it behind a CSS variable so it can swap.

Both Bluu Next (Velvetyne) and Apfel Grotezk (Collletttivo) are SIL OFL. Self-host them in the repo. Font files are embedded in `bigsquare-style-sheet-v6.html` and can be extracted from there.

Note: the brand owner is not fully sold on the display font. Treat it as locked for v1 but do not hard-code font names anywhere outside the CSS variables.

```css
--d: 'BluuNext', Georgia, serif;
--t: 'Apfel', 'Helvetica Neue', Arial, sans-serif;
--m: 'IBM Plex Mono', ui-monospace, Menlo, monospace;
```

Scale (starting point, refine in the style guide):
- H1: 64px desktop / 40px mobile, line-height 1.05, Bluu Next Bold
- H2: 44px / 32px, line-height 1.1, Bluu Next Bold
- H3: 24px / 20px, Apfel Fett
- Body: 18px / 17px, line-height 1.6, Apfel Regular
- Eyebrow: 13px, mono, uppercase, letter-spacing 0.08em, `--mid`
- Big metric: 72px / 48px, Bluu Next Bold, `--acc`

## Spacing and layout
- Max content width 1200px. Wide sections (hero, marquee, CTA band) go full bleed.
- Section padding 96px top and bottom on desktop, 64px on mobile.
- 8px base grid.
- Buttons: pill shape, 16px 28px padding, Apfel Fett, primary is `--acc` with `--onacc` text, secondary is outlined `--ink` on light or `--ondark` on dark.
- Cards: `--surf` background, 1px `--line` border, 16px radius, no heavy shadow. A soft shadow appears only on hover.

## Effects and motion
- Scroll-triggered fade-up on section entry (Framer Motion, 0.5s, 16px travel, stagger children 60ms).
- Hero: full-bleed video with a `--darkpanel` overlay at 55 to 65 percent so white type reads cleanly.
- Logo marquee: continuous horizontal scroll, pauses on hover, grayscale logos that go full color on hover.
- Big numbers count up on entry.
- Buttons: slight scale (1.02) and shadow on hover, 150ms.
- Nav: transparent over the hero, becomes solid `--paper` with a 1px `--line` bottom border after 40px of scroll, with a subtle backdrop blur.
- Three.js: one hero or "Obsidion portal" section may use a light 3D element (a slowly rotating wireframe square or grid) if it stays under 200KB and does not hurt LCP. Optional, not required for v1.
- Respect `prefers-reduced-motion`: disable marquee motion and count-ups, keep fades instant.

## Do not
- No gradient buttons.
- No glassmorphism cards as a default pattern.
- No stock photos of people shaking hands. Real team, real clients, or abstract brand shapes only.
- No more than one accent color on screen at once (blue). Navy is for depth, not a second accent.
