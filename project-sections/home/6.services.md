## Design direction

- Light section, GridLines on. SectionHeader: eyebrow row + H2; right column holds the support line "No descriptions here. Each service page carries the detail." at `--text-small` `--mid`, or stays empty if that reads as filler.
- Each group is a **header rule row** spanning the container: `[01]` mono in `--sec-acc` left, group name in Apfel 700 at `--text-h3`, `↗` right. The row links to the group's anchor on /services/. Hover: directional fill (fills from the bottom, exits through the top, label flips to `--sec-bg`).
- Under each header row, the group's services as **quiet rule rows in a two-column grid** (Organic's six items make three rows of two): label Apfel 500 at 16px `--ink` left, small `→` right, 1px bottom hairline. Hover: arrow slides 4px, hairline darkens to `--sec-ink`, 250ms. Every item links to its slug from `project-guidelines/sitemap.md`.
- Spacing: 48px between groups. The audit line is a rule link (STYLE_GUIDE 6.1 #4), right-aligned. Not a bracket: the annotation budget is spent.
- No icons in this section. The mono indexes and rules are the iconography.

## Build with

Existing: `Section`, `Container`, `GridLines`, `SectionHeader`, mono meta, `components/motion/{SeparatorIn,Reveal}.tsx`.

New this phase: `RuleLink` (single hairline row with arrow) and `RuledLinkTable` (header row + item rows), both shared: the footer (phase 2I) and service pages reuse them. The directional fill lives in CSS per STYLE_GUIDE 6.1 so it works on any section ground.

## Motion

- Header rule rows: SeparatorIn draws each group's hairline, text Reveals, 80ms stagger between groups.
- Item rows: Reveal in column order inside each group, 40ms stagger, once.
- Hover motion per 6.1 (fill 300ms swoop; arrow slide 250ms).
- Reduced motion: settled; hovers become color-only.

## Mobile (375)

Item rows collapse to a single column. Header rows keep index + name + arrow on one line. Tap targets at least 44px tall. The audit rule link goes full width.
