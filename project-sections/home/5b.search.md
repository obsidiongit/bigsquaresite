## Design direction

- Tint section (`theme="tint"`, `anchor="search"`), `py-section-y-lg`. Content `relative z-10`. Width: EDGE outer, content self-caps at `mx-auto max-w-[52rem]`, all centered.
- Headline at `--text-h2` (Bluu display voice optional; test both). Support at `--text-body` in `--sec-mid`.
- The composer mockup: a wide `bg-paper rounded-[24px] border border-sec-line` panel with soft padding, reading as a chat input. Top line: the typed text (or placeholder "How can I help you today?" between queries) at `--text-lead` with a blinking caret. Bottom row: plus glyph left; right side a quiet mono model label + mic and waveform glyphs. Send arrow chip appears in `--acc` once text exists. Below the panel: 4 suggestion chips (mono, pill-shaped, `--surf` ground): "Find a service", "Compare options", "Get a quote", "Near me". The entire mockup is decorative and `aria-hidden`; every meaningful message lives in the real copy above.
- Cues suggest the Claude composer without cloning trade dress: our radii, our tokens, our type. No Anthropic logo, no starburst.

## Typing animation

- JS typewriter in the component (variable-length queries rule out CSS steps): type ~45ms/char with slight jitter, hold 1.8s with the send arrow lit, delete-or-fade 300ms, 600ms placeholder rest, next query. Loop forever, pause offscreen via `useInView`.
- Caret: 2px `--acc` bar, `wgt-caret` blink (steps(2), ~1s).
- Deterministic first paint: renders the placeholder state on SSR, starts typing on mount.
- Reduced motion: static composer showing query 1 complete, send arrow lit, no caret blink, no cycling.
