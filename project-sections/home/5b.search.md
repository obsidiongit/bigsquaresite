## Design direction

- Tint section (`theme="tint"`, `anchor="search"`), `py-section-y-lg`. Content `relative z-10`. Width: EDGE outer; the copy self-caps at `mx-auto max-w-[56rem]` centered; the mockup panel runs the FULL EDGE width (v2.1: no inner cap; the panel is the section's magazine-scale moment, like FeaturedWork's media).
- Headline at `--text-h2` in the display face (Bluu, matching ProblemStrip's h2 call). Support at `--text-body` in `--sec-mid`.
- **The mockup is a depicted product, not a designed component.** Inside the `aria-hidden` frame the ChatGPT composer is rendered with ChatGPT's own values, hard-coded, NOT our tokens: white card, ~28px radius, hairline `#e3e3e3` border + soft shadow, `#0d0d0d` text, `#8f8f8f` "Ask anything" placeholder, plus glyph left, mic + black-circle voice button right (the circle's waveform swaps to the white up arrow once text exists), neutral system sans instead of the brand faces. This is the one sanctioned token/typography exception on the site (STYLE_GUIDE changelog "depicted product UI"); every other pixel of the section is token-native.
- The viewport panel: `bg-paper rounded-[24px]` with `overflow-hidden`, 320px tall at 375 up to 560px at desktop (v2.1 scale-up). The composer (720px max) sits centered inside a scalable stage; the camera move is a transform scale on that stage (origin near the first typed character), so zoomed-in states crop the composer large, exactly like the video.
- No suggestion chips: the reference frames crop below the composer and the panel stays clean.
- The entire mockup is decorative and `aria-hidden`; every meaningful message lives in the real copy around it.

## Choreography (one loop ~7s per query, 3 queries per cycle)

1. Rest: camera zoomed IN on the empty input, "Ask anything" placeholder, ~1.1s.
2. Placeholder fades, caret appears, the query types at ~40-70ms/char with jitter (longer pause after punctuation). The voice circle swaps to the send arrow at the first character.
3. At ~60% of the query the camera eases back OUT (~1.15s, house ease) while typing continues; the finished query holds ~1.9s on the full composer, arrow lit.
4. Text fades, the camera returns to the zoomed rest, the placeholder returns, next query. Loop forever, pause offscreen (`.wgt` / `data-play` gate, useWidgetLoop).

- JS state machine in the component (variable-length queries + the camera move rule out pure CSS); the only CSS keyframe is `wgt-caret` (steps, cut not fade).
- Caret: 2px `#0d0d0d` bar, ChatGPT's, not ours.
- Deterministic first paint: SSR renders the zoomed-in rest state; typing starts on mount in view.
- Reduced motion: static zoomed-out composer, query 1 complete, arrow lit, no caret, no cycling.
