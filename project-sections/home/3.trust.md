## Design direction

- Light section, compact: 48px vertical padding, sits under the hero info bar. No Nº label (utility section).
- Each logo lives in a **tile**: `--surf` background, 1px `--line` border, radius 16, logo grayscale and height-normalized to 32px inside comfortable padding (tile roughly 150x80). Full color on hover, 250ms.
- One marquee row (8 to 15 logos does not justify two offset rows). Track duplicated for the seamless loop, duplicate `aria-hidden`.
- Soft fade masks at both edges.

## Motion

- CSS keyframe track at ~50px/s desktop, 35px/s mobile. Pauses on hover.
- Velocity coupling (STYLE_GUIDE 7.5): scroll velocity times ~0.5 added to track speed, clamped to 3x base, decaying 0.9 per frame. This is the page's ONE velocity-reactive element.
- Reduced motion: no marquee; render a static centered wrapped grid of the same tiles.

## Mobile (375)

Same marquee at 35px/s, tiles slightly smaller (logo 28px). Fade masks stay. Reduced-motion grid goes two columns.
