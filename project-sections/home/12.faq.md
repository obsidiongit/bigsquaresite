## Design direction

- Light section. Utility: no Nº label, GridLines optional (skip if the narrow container makes rails feel empty; note the call in review).
- Max width 800px, centered. Eyebrow + H2 centered above the container.
- One bordered container: 1px `--line`, radius 16, `divide-y` hairlines between items. Question row: Apfel 700 at 18px left, chevron right. Answer: body text in `--mid`.
- One item open at a time.
- FAQPage JSON-LD emitted from the same data array that renders the accordion. One source.

## Steal from

- Metacci, the bordered objection accordion: `../reference-images/metacci/metacci-home-desktop-12.png`

## Mobile (375)

Full width minus gutters. Questions wrap to two lines; chevron stays top-right. Tap targets 44px minimum.
