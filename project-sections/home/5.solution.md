## Design direction

- Light section (`theme="light"`, `anchor="solution"`), `py-section-y-lg`. Content `relative z-10`. Width: EDGE, no Container, no rails, no Nº.
- Headline in Bluu Next (`font-display`) at `--text-statement`: the page's single statement-scale moment, relocated here from the retired v2 problem headline. Left-aligned.
- Header row under it: intro at `--text-lead` in `--sec-mid` capped ~52ch left; the two Pills right-aligned on the same baseline row (stack on mobile).
- Cards: 3-up equal grid, `gap-6`. Each `bg-surf rounded-[24px] border border-sec-line p-6 md:p-8`. Top: the widget vignette on a `bg-paper rounded-[16px]` inset panel (inner elements radius 8). Below: title at `--text-h3` Apfel 700, one-liner at `--text-body` in `--sec-mid`. Cards never hover (not links).

## Widget specs (timing measured from the reference videos, then calmed)

House rules for all three: pure CSS `@keyframes` (new `wgt-*` block in globals.css, groundwork), transform/opacity only, `--ease-house`/`--ease-swoop`, no bounce. One shared loop duration per widget; every element sequences via percentage keyframes + `animation-delay`, so the card is a single synchronized timeline with a seamless repeat. Root class `.wgt`; paused unless `data-play` (set by `useInView`). Reduced motion: CSS kill + component renders the settled end frame. No fake numbers, no fake names (their videos use "Eric" and real-looking dates; ours never do).

### 1. Calendar (No Long Term Contracts)
Reference: `Calendar-Week.mp4`, 3.05s, 3 beats. Ours: **4.5s loop, 3 beats of 1.5s** (calmer hold).
- Panel: month label between two chevron buttons, hairline, then a 5-cell week strip: day-name over day-number (Fri 1 through Tue 5), cells rounded-8.
- Beat cycle: month label swaps (Jan, Feb, Mar analogs; generic "Month 1" style is too fake-averse even for us: use real month names, a calendar is not a claim), active cell moves (cell 3, cell 4, cell 1), each transition a ~300ms cross-fade of the strip + label.
- Active cell: `--acc` fill, white numeral. Idle cells: `--paper` on the inset, `--sec-mid` day names.

### 2. Task list (Transparency)
Reference: `Task-List.mp4`, 3.25s, sequential check-off. Ours: **5s loop**.
- Panel: "Tasks" title row with a small glyph, hairline, two task rows: circle checkbox, task title (Apfel 500), one-line sub (small, `--sec-mid`), a tag chip + a blurred value-bar where their fake date sits.
- Task titles generic and true to what we do: "Launch the search campaign" / "Send the monthly report". Chips: "Paid Search" / "Reporting" in mono, `--surf` ground. No person names, no dates.
- Beats: 0 to 1.5s both unchecked; ~1.5s row 2's circle fills `--acc` with a white check (scale-in 200ms), title strikes through (scaleX left-origin 250ms) and row dims to 45%; ~3s row 1 checks the same way; ~4.5s quick 300ms fade-reset; loop.

### 3. Channel bars (Full Approach)
Reference: `All-Channels.mp4`, 3.30s, grow-and-hold. Ours: **5.5s loop**.
- Panel: "All Channels" title row with chart glyph, hairline, 3 labeled bar rows + faint tick gridlines. Labels: "Paid Search", "Calls", "Social" (generic service words, not platform brands). Ticks unlabeled (no fake axis numbers).
- Beats: 0.5s axes only; bars grow left to right (scaleX, 600ms `--ease-swoop`, 120ms stagger) to fixed widths ~85/60/35%; hold ~3.5s; 300ms retract-reset; loop.
- Bar color: this is the one place the widget system uses more than one fill. Stay on brand: `--acc`, `--acc2`, and `--mid` (never a traffic-light trio).

- Headline BaselineReveal; header row + cards Reveal stagger 60ms.
- Widget loops start when in view, pause offscreen, run forever otherwise. This is the region's live-element budget: three loops on screen at once max, all quiet.
- Reduced motion: settled frames (row checked, bars grown, calendar static), zero looping, entrance reveals settle instantly.
