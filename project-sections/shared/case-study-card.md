# Case Study Card Component (shared)

Props: metric (string), metricLabel, clientName, oneLine, slug, optional logo.

Layout: metric huge at top (Bluu Next Bold, `--acc`), label under it (`--mid`), client name (Apfel Fett), one line, arrow link "See the results".

Rules: metric must come from a real case study file. Client name can be replaced with "[industry], [n] locations" when the client cannot be named.
