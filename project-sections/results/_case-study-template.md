# Case Study Page Template

Copy this file once per case study. Name it by slug. 5 or 6 at launch. Real data only, every number traces to the account.

## Page
- URL: /results/[slug]/
- Title tag pattern: "[Result] for [Client type] | BigSquare" (e.g. "34% Lower Cost Per Lead for a Home Services Franchise")
- Meta description: `[PLACEHOLDER]`
- OG image: page-specific per seo-requirements.md. `[PLACEHOLDER: design]`

## Section order
1. Hero: eyebrow "CASE STUDY", H1 with the headline result, client name or "[industry], [n] locations" if the client cannot be named, one-line summary.
2. The numbers: 3 metrics in a row (metric block pattern). `[PLACEHOLDER: metrics]`
3. The situation: 2 to 3 short paragraphs. Where they started, what was broken.
4. What we did: 3 to 5 steps, plain words, each naming the service used (linked).
5. The result: 1 to 2 paragraphs, restating the headline number with the time window.
6. Quote from the client, if one exists (testimonial card). Real names only, or skip the section.
7. Services used: link list.
8. CTA band (shared) with body: "Want numbers like these? Book a call and we will show you what we would do first."
